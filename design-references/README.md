# Design References

从 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 拉取的设计系统文件。

## 使用方法

1. 选一个你喜欢的风格
2. 把对应的 DESIGN.md 复制到 `blog-new/DESIGN.md`
3. 告诉 AI "按照 DESIGN.md 的规范来写页面"

## 可选风格

| 风格 | 文件 | 特点 |
|------|------|------|
| Mintlify | `mintlify-DESIGN.md` | 白色清爽、绿色强调、阅读优化、文档风 |
| Vercel | `vercel-DESIGN.md` | 黑白极简、Geist 字体、shadow-as-border |
| Linear | `linear-DESIGN.md` | 暗色优先、紫色强调、超精确、工程感 |
| Resend | `resend-DESIGN.md` | 纯黑画布、冰蓝边框、三字体体系、杂志感 |
| Notion | `notion-DESIGN.md` | 暖色极简、衬线标题、纸质触感、温暖亲切 |
